# Протокол Коннор — скелет приложения

Рабочий прототип PWA по спецификации «Протокол Коннор». Все данные хранятся
локально в браузере (localStorage) — без серверов и аккаунтов.

## Что уже работает

- **Дашборд** — статы персонажа, стрик, счётчик тренировок за неделю, ежедневные квесты (белок / шаги / вес).
- **Сегодня** — календарная полоса на всю неделю (видно, где силовая, где табата, где отдых — не нужно гадать, почему сегодня «пусто», это часть плана, а не баг) + тренировка выбранного дня, с отметкой выполнения и начислением опыта. Отметить выполненной можно только реально сегодняшнюю тренировку, остальные дни — предпросмотр. Приложение не диктует список упражнений — только область фокуса («всё тело», «верх», «низ + баланс сёрфера» и т.д.), что конкретно делать в рамках фокуса — решаешь сама. Для силовых тренировок можно выбрать источник — «домашняя библиотека» или **FitStars** (лёгкая силовая программа платформы) — опыт начисляется одинаково.
- **Квесты** — челленджи (сквозные достижения поверх обычных циклов), прогресс недели, история за 14 дней, журнал замеров.
- **Босс** — форма ввода результатов ближайшего фит-теста, автоматическая проверка порогов, повышение ранга при прохождении.
- **Персонаж** — лестница рангов, статы, график роста каждого стата по неделям (спарклайн + дельта за 10 недель), кнопка сброса прогресса (для тестирования).

Прогрессия нагрузки (2 силовых + 2 табаты + 1 аштанга → … → 4 силовых + 2 табаты + 2 аштанги + animal flow), пороги боссов и финальные цели зашиты по ранее согласованной спецификации — их легко поменять в начале файла `index.html` в блоках `RANKS`, `WEEK_PLANS`, `BOSS_DEFS`, `CHALLENGE_DEFS`.

## Челленджи (v0.3)

Сквозные достижения поверх обычных дневных/недельных циклов, отслеживаются автоматически по уже собранным логам:

- **«Я вернусь»** — 28 дней подряд без пропуска запланированных тренировок.
- **«Судного дня не будет»** — 30 дней подряд норма белка (120 г+).
- **«Разведка боем»** — 14 дней подряд 10 000+ шагов.
Список легко расширить — каждый челлендж это просто `{key, title, desc, target, check(date)}` в массиве `CHALLENGE_DEFS`. Новый челлендж не требует миграции данных: он читает уже накопленные `dailyLogs`/`workouts`, поэтому при добавлении сразу подхватывает прошлый прогресс, если он ему соответствует. Отдельно хранится `challengeMeta` — счётчик, сколько раз каждый челлендж был выполнен целиком (не только текущий стрик).

## История статов (v0.4)

На вкладке «Персонаж» появился график роста каждого стата по неделям — спарклайн (маленькая линия без осей, только тренд) плюс дельта за последние 10 недель. Технически: раз в день, при любом начислении опыта или заходе на вкладку «Персонаж», сохраняется снимок `{date, stats}` в `statHistory`; график строится по последнему снимку в каждой неделе. Так как это добавлено сейчас, а не с самого начала, за прошлые недели данных не будет — линия начнёт вытягиваться от текущего момента.

## Как проверить прямо сейчас

Просто открой `index.html` в браузере (двойной клик или перетащить в окно браузера) — приложение полностью рабочее без установки. Данные сохранятся между заходами на этом же устройстве и в этом же браузере.

## Как установить на телефон/компьютер как настоящее приложение

Для установки (иконка на главном экране, отдельное окно, офлайн-режим) нужно, чтобы файлы отдавались по `https://` — просто открыть файл с диска для этого недостаточно. Самый простой бесплатный вариант:

1. Зарегистрируй бесплатный аккаунт на [GitHub](https://github.com), если его ещё нет.
2. Создай новый репозиторий, например `connor-protocol`.
3. Залей туда все файлы из этой папки (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) — через веб-интерфейс GitHub кнопкой «Add file → Upload files», код писать не нужно.
4. В репозитории: Settings → Pages → Source → выбрать ветку `main` и папку `/root` → Save.
5. Через минуту GitHub даст ссылку вида `https://<твой-логин>.github.io/connor-protocol/`.
6. Открой эту ссылку на телефоне (Chrome) — появится баннер «Добавить на главный экран» / пункт в меню браузера. На компьютере в Chrome/Edge — иконка «Установить приложение» в адресной строке.

Дальше можно продолжать пользоваться исходным файлом в разговоре или прямо на GitHub — при следующем изменении просто заменить файлы в репозитории.

## Календарь и дата старта (v0.5)

- На вкладке «Сегодня» появилась полоса из 7 карточек (текущая неделя, Пн–Вс) — на каждой видно тип тренировки или «Отдых», галочка при полном выполнении дня, подсветка сегодняшнего и выбранного дня. Клик по карточке открывает предпросмотр плана этого дня ниже (без возможности отметить — отметить можно только настоящий сегодняшний день).
- На вкладке «Персонаж» появилось поле «Дата старта программы» — если её сохранить (например, `2026-08-31`), на вкладке «Сегодня» до этой даты будет виден баннер-обратный отсчёт. Само приложение при этом не блокируется — тренироваться и копить логи можно и до официального старта, баннер чисто информационный.
- Важно понимать: если сегодня показывает «Отдых» — это, скорее всего, не баг, а день недели, который в текущем ранге запланирован как выходной (например, у Цивильной это пятница и воскресенье). Полоса недели как раз для того, чтобы это было видно сразу, а не только когда открываешь конкретный день.

## Правки после первого живого теста (v0.6)

- **Календарь недели** теперь горизонтально прокручиваемый, а не жёсткая сетка на 7 колонок — на узких экранах или при увеличенном системном шрифте раньше могло выламывать вёрстку, сейчас карточки дней просто уезжают в скролл и ничего не ломается.
- **«Нет кнопки Отметить выполненным»** — это не баг: если сегодня по плану ранга выпадает на день отдыха (после переноса пт/сб именно суббота стала отдыхом для Цивильной), кнопки быть не должно, тренировки в этот день нет. Календарная полоса как раз и нужна, чтобы сразу было видно, какой день отдых, а какой нет — можно щёлкнуть на соседний день и посмотреть его план.
- **Челленджи показывали прогресс в самый первый день, до единого лога** — реальный баг, исправлено дважды. Первая попытка (`meta.installedAt`, дата первого запуска) оказалась недостаточной: в инкогнито при первом же открытии сегодняшний день — выходной — всё равно засчитывался автопроходом, просто потому что приложение было открыто. Сейчас используется `meta.firstActivityDate` — дата первого **реального** действия (сохранён дневной квест или отмечена тренировка), а не дата запуска. Пока не залогировано вообще ничего, все челленджи показывают честный 0.
- **Сервис-воркер обновлён** (`connor-protocol-v2`) — раньше он был настроен «кэш в приоритете», из-за чего после обновления файлов на GitHub телефон мог продолжать открывать старую сохранённую версию приложения. Теперь сеть в приоритете, кэш — только запасной вариант на случай отсутствия интернета. **После обновления файлов на GitHub один раз полностью закрой приложение (смахни из списка недавних) и открой заново** — это даст сервис-воркеру шанс подтянуть новую версию.

## Рассинхрон «сегодня» в шапке и в календаре (v0.7 → настоящая причина в v0.8)

Первая попытка (v0.7) чинила реальную, но не единственную проблему: день во вкладке «Сегодня» хранился как замороженный объект `Date()` вместо «текущая дата, если не выбран другой день». Это исправление осталось в силе, но не решило то, что было на скриншотах.

**Настоящая причина (v0.8):** ключ даты (`todayKey`) собирался через `d.toISOString()`, а это **время в UTC**, не локальное время телефона. Для часовых поясов восточнее UTC (у тебя UTC+5) это систематически — в любое время суток, не только под утро — сдвигает дату локальной полуночи на день назад: полночь субботы по Москве/Ташкенту/Карачи — это ещё 19:00 пятницы по UTC. Календарь строит карточку субботы именно как «локальная полночь субботы», конвертирует её в UTC-ключ для сравнения — и получает пятницу. Отсюда суббота подсвечивалась как «сегодня», хотя текст ниже (построенный без этого бага) правильно писал «пятница».

Исправлено — `todayKey` теперь берёт год/месяц/день из локального времени напрямую, без какой-либо конвертации в UTC. Это единственное место, где использовалась `toISOString()`, так что чинится сразу везде: календарь, дневные логи, замеры, история статов, челленджи.

## Кэширование полностью отключено (v0.9)

Сервис-воркер несколько раз подряд был источником путаницы — телефон мог тихо продолжать работать со старой версией логики уже после того, как файлы на GitHub обновлены. Пока идёт активная доработка, отключила кэширование совсем:

- Регистрация сервис-воркера убрана из `index.html` — новый больше не ставится. Если на телефоне уже стоит старый (с прошлых версий), он снимается автоматически при следующем открытии.
- Сам файл `sw.js` оставлен в проекте нетронутым — просто больше не подключается. Когда логика стабилизируется и захочется офлайн-доступ (например, для тренировок без wifi в зале), регистрацию можно будет вернуть одной строкой — сам файл к этому готов.
- В `index.html` добавлены мета-теги `Cache-Control: no-cache, no-store, must-revalidate` — это просьба к браузеру не кэшировать саму страницу подолгу на уровне обычного HTTP-кэша (независимо от сервис-воркера).

Итог: теперь каждое открытие приложения гарантированно идёт в сеть за актуальной версией файла. Расплата — без интернета совсем свежий запуск (не из уже открытой вкладки) может не открыться; данные при этом всё равно в безопасности, они в localStorage на устройстве и от сети не зависят.

## Схематичная фигура персонажа (v1.0)

На вкладке «Персонаж» теперь первая карточка — схематичный силуэт, который «наливается» снизу вверх, как сосуд, по мере роста статов. Заполненность = среднее по всем шести статам (0–100%), цвет заливки — акцентный цвет темы. Рядом — процент, текущий ранг и подсказка, какой стат сейчас самый слабый (это который меньше остальных пяти) — небольшой намёк, куда стоит подтянуть тренировки. На нуле фигура полностью пустая (только контур), к финалу — полностью залита. Реализовано на чистом SVG (маска-клип в форме фигуры + прямоугольник, который меняет высоту), без картинок и библиотек.

## Экспорт / импорт данных (v1.1)

На вкладке «Персонаж» появилась карточка «Резервная копия»:

- **Скачать резервную копию** — сохраняет весь прогресс (статы, логи, тренировки, боссы, замеры, историю, настройки) в один `.json`-файл. На Android это обычное скачивание в папку «Загрузки». На iPhone Safari файл иногда открывается в новой вкладке вместо прямого скачивания — тогда его нужно сохранить через «Поделиться → Сохранить в Файлы» (в приложении об этом есть подсказка после скачивания).
- **Восстановить из файла** — загружает ранее скачанный `.json` обратно, полностью заменяя текущий прогресс (с подтверждением, случайно не нажмётся).

Это не автоматический бэкап в облако — весь прогресс по-прежнему хранится только в этом браузере на этом телефоне. Экспорт нужно делать руками, но зато теперь смена телефона, переустановка браузера или случайная очистка данных сайта не обнуляют месяцы прогресса — если вовремя скачать копию. Стоит взять за привычку — например, раз в неделю вместе с замерами.

## Момент повышения ранга, флейвор-подсказки, прогресс до ранга (v1.2)

- **Момент повышения ранга** — теперь при прохождении босса вместо тихого тоста появляется полноэкранный тёмный HUD-экран со скан-линией и свечением: «Новый ранг: …». Закрывается по кнопке, по тапу в любом месте экрана или сам через ~4 секунды. Сделан намеренно вне обычной светлой/тёмной темы приложения — это системное сообщение, а не часть интерфейса, поэтому у него свои фиксированные цвета. Уважает `prefers-reduced-motion` — если у человека в настройках отключена анимация, скан-линия и мигание текста не проигрываются, экран просто появляется статично.
- **Флейвор-подсказки** — на дашборде появилась карточка «Диагностика» с одной строкой в строгом, по делу тоне, привязанной к самому слабому стату на сегодня (три варианта текста на каждый стат, чтобы не приедалось). Подсказка стабильна в течение дня — не дёргается при каждом заходе в приложение, меняется только при смене даты или при смене самого слабого стата.
- **Прогресс до следующего ранга** — на дашборде теперь есть отдельная полоса «До следующего ранга» с текущим опытом и порогом (например, «42/120 XP»), а не только список порогов на вкладке «Персонаж». Отдельно уточнено, что опыт даёт только право на попытку — сам переход по рангу происходит через пройденный босс-тест.

## Фигура по зонам тела и личные рекорды (v1.3)

- **Фигура персонажа по зонам** — раньше заливка была одна на всю фигуру, по среднему значению всех статов. Теперь каждая зона тела наливается независимо, от своего стата:
  - **Голова** — КООРД (координация)
  - **Грудь** (верх торса) — ВЫН (выносливость)
  - **Корпус** (низ торса) — ДИСЦ (дисциплина: белок/шаги/взвешивания/выполнение квестов)
  - **Руки** — СИЛ (сила)
  - **Бёдра** (верх ног) — БАЛ (баланс)
  - **Голени** (низ ног) — КОНТ (контроль тела/гибкость)

  Под фигурой добавлена подпись с этой раскладкой, чтобы не пришлось запоминать. Теперь по фигуре видно не только «сколько процентов в среднем», а прямо какие зоны прокачаны, а какие просели — например, отдельно накачанные руки при слабом корпусе будут видны как контраст между полностью тёмными руками и почти пустым торсом.
- **Личные рекорды** — на вкладке «Персонаж» появилась карточка «Личные рекорды», которая считается из истории прохождения боссов-фит-тестов (`bossTests`) — данные там и раньше копились, но нигде не собирались в сводку. Показывает лучший результат по каждому показателю (макс. отжимания, макс. подтягивания, лучшая планка, лучший баланс и т.д., а для поп-апа — наоборот, минимальное время) вместе с датой, когда он был показан. Аштанга-серии считаются отдельно — как «последний раз, когда серия была пройдена чисто». Карточка пустая до первого пройденного теста-босса.

## Мелкие правки (v1.3.1)

- Кнопки внизу вкладок («Сохранить», «Сбросить весь прогресс» и т.п.) больше не заезжают под нижнюю панель меню. Причина была не в размере отступа, а в том, что `padding-bottom` висел на `<body>`, у которого стоит `height: 100%` — из-за этого отступ «схлопывался», когда контент и так был выше высоты экрана. Перенесли отступ на `<main>`, у которого такого ограничения нет.
- Первый ранг переименован: «Цивильная» → «Новичок».

## Слабое звено, прогноз ранга, ретро-терминал (v1.4)

- **«Слабое звено» — быстрое действие** — новая карточка на дашборде: показывает, какой стат сейчас просаживает сильнее остальных, и предлагает конкретное мини-упражнение на 3–5 минут именно под него (три варианта на стат, меняются по дню, как и флейвор-подсказки). Кнопка «Сделал(а) — отметить» даёт +4 к этому стату и работает один раз в день — это не замена основному плану тренировок, а способ подлатать явный пробел, не дожидаясь следующего дня по расписанию.
- **Прогноз финального ранга** — на дашборде появилась карточка «Прогноз: финальный ранг»: по среднему темпу набора опыта с начала реальной активности оценивается дата, когда опыта хватит для попытки Босса V. Явно уточнено, что это не гарантия ранга — сам переход всё ещё даёт только пройденный тест.
- **Тема «ретро-терминал»** — на вкладке «Персонаж» в карточке «Оформление» появился переключатель альтернативной темы: зелёный монохром, моноширинный шрифт, лёгкие сканлайны поверх интерфейса. Работает независимо от системной светлой/тёмной темы, переключается вручную и сохраняется в настройках.

## Контраст в ретро-терминале (v1.4.1)

- В теме «ретро-терминал» кнопки и плашка ранга рисовались белым текстом поверх `var(--accent)`/`var(--good)` — а в этой теме обе переменные стали ярким неоновым салатовым, из-за чего белый текст пропадал. Добавлена отдельная переменная `--on-bright` для текста поверх таких заливок: в обычной теме она белая, как и была, а в ретро-терминале — тёмный, почти чёрный зелёный, чтобы вписаться в общую монохромную гамму вместо резкого контраста.

## Побочный квест дня (v1.5)

- На вкладке «Сегодня» появилась карточка «Побочный квест дня» — небольшая необязательная доп. задача (например, «10 отжиманий без остановки» или «50 приседаний за один заход»), отдельная от основного плана тренировок и от «Слабого звена» на дашборде. Показывается только в тренировочные дни (в дни отдыха карточки нет) и только для сегодняшнего дня — как и у обычных слотов тренировки, отметить выполнение предпросмотра будущего дня нельзя. Квест меняется каждый день (девять вариантов на разные статы — сила, выносливость, баланс, гибкость, координация, дисциплина), отметка одноразовая на день, даёт небольшую фиксированную прибавку (+2–3) к своему стату.

## Распорядок буднего дня (v1.6)

- На вкладке «Сегодня» появилась карточка «Распорядок буднего дня» — фиксированное расписание тренировок, кардио и приёмов пищи по времени (08:00 тренировка, 09:00 завтрак, 11:30 перекус, 13:00–13:15 обед, 15:00 тренировка, 16:00–16:30 перекус-белок, 18:30–19:00 ужин, 20:30 кардио эллипс, 21:30 перекус-белок). Показывается только по будням (Пн–Пт) — в выходные карточки нет, у них другой ритм. Пункты, время которых уже прошло сегодня, зачёркиваются и тускнеют, актуальный на данный момент пункт подсвечивается, будущие — обычным текстом. Подсветка обновляется раз в минуту, пока вкладка открыта. Оформлено моноширинным шрифтом наподобие распечатки.

## Убрана тема «ретро-терминал» (v1.6.1)

- По просьбе — минималистичная светлая/тёмная тема больше нравится, чем зелёный монохром со сканлайнами. Убраны: переключатель и карточка «Оформление» на вкладке «Персонаж», сама тема и её CSS-переменные, поле `settings.scheme`. Осталась только исходная светлая/тёмная тема, которая и раньше переключалась системными настройками устройства.

## Галочка «Дневник» (v1.7)

- В карточку «Ежедневные квесты» на дашборде добавлена галочка «Дневник» — отметить, что коротко подвела итог дня/записала мысли. Даёт +1 к ДИСЦ при сохранении — меньше, чем белок/шаги/вес (+2 каждый), намеренно: это более лёгкое, необязательное действие, а не измерение конкретной цифры. Отдельного текстового поля для самого дневника в приложении нет (это ломало бы принцип «только локально и просто») — подразумевается, что записи ведутся где угодно (бумажный блокнот, заметки на телефоне), а галочка — просто фиксация факта и небольшая награда за привычку.
